A single 3AM text from a smart fridge that has been awake all night watching its owner. The fridge reports that the cake hidden behind the vegetables has filed a missing persons report, then lands the cold two-beat punchline: "3AM update: the cake you hid behind the vegetables has filed a missing persons report. It misses you. I don't." One line, 110 characters, no follow-up needed — it reads exactly like a lock-screen notification from a machine that decided 3AM was the moment to speak.

## Run it

```sh
python3 main.py
```
